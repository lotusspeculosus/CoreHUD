# Security policy

Please report security problems **privately** through
[Report a vulnerability](https://github.com/lotusspeculosus/RigSense/security/advisories/new),
not as a public issue.

Examples: a way to make RigSense write to hardware, run code from a crafted `.rigpanel` file,
or anything that could disable or bypass the 12V-2x6 safety alerts.

Only the latest release is supported with fixes.
